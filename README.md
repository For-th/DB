# ArenaPH: Esports Tournament Management Database

A relational database designed and implemented for managing esports tournaments, teams, players, matches, and tournament results.

Academic Project | October 2026 – November 2026

## Tools Used

- MySQL
- phpMyAdmin
- SQL

## Features

- Entity-Relationship Diagram (ERD) with 15+ related tables
- Primary keys and foreign keys to keep records connected and consistent
- Records for tournaments, teams, players, matches, and prize distribution
- Team assignments to tournaments
- Queries for filtering and retrieving data, such as [example: finding all matches of a team]

## Database Structure

Main tables include:

Games – Stores information about supported esports games.

Players – Stores player profiles and information.

Teams – Stores registered esports teams.

Tournaments – Stores tournament details and information.

Tournament Teams – Records the teams participating in each tournament.

Matches – Stores scheduled and recorded tournament matches.

Match Results – Records match scores, outcomes, and winning teams.

Prizes – Stores information about tournament rewards.

Tournament Prizes – Assigns prizes to tournaments and records their winners.


## How to Use

1. Open phpMyAdmin and create a new database named arenaph.
2. Click the Import tab.
3. Choose the .sql file from this repository and click Import.
4. The tables and sample data will be loaded.
